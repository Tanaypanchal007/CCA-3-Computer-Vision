# CCA 3 – Computer Vision Assignment

## Project Overview

This project demonstrates practical applications of Computer Vision using Python and popular image processing and machine learning libraries.

The assignment covers image restoration, image segmentation, feature extraction, feature matching, object detection, and motion estimation.

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Ultralytics YOLO
- Jupyter Notebook

## Units Covered

### Unit 3: Image Restoration and Segmentation
- Gaussian Noise
- Salt-and-Pepper Noise
- Image Quality Evaluation using PSNR and SSIM
- Image Thresholding
- Morphological Operations
- Canny Edge Detection
- Watershed Segmentation

### Unit 4: Feature Extraction and Matching
- Histogram of Oriented Gradients (HOG)
- SIFT Feature Matching
- Image Rotation and Resizing

### Unit 5: Object Detection and Motion Estimation
- Haar Cascade Face Detection
- YOLO Object Detection
- Frame Differencing
- GMM Background Subtraction
- Lucas–Kanade Optical Flow

## Installation and Execution

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Create and activate a Python virtual environment.
4. Install the required libraries:

```bash
pip install -r requirements.txt
```

5. Launch Jupyter Notebook:

```bash
jupyter notebook
```

6. Open `CCA_3_Computer_Vision_Assignment.ipynb`.
7. Run the notebook cells in sequence.

## Input Data

The project uses personal photographs and a self-recorded video stored in the `data/` directory.

## Output

The processed images and visualizations are saved in the respective folders inside `outputs/`.
